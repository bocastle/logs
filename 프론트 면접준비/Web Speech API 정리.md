# Web Speech API 정리

## 핵심 요약

- 손을 쓰기 어려운 상황의 입력과 안내를 보완할 수 있다.
- 지원 브라우저와 언어 품질 차이가 크다.
- 사용자 제스처 뒤에 음성 출력을 시작한다.

## 개념 설명

Web Speech API는 브라우저에서 음성 인식과 음성 합성을 제공하는 API 묶음이다.

`SpeechRecognition`은 마이크 입력을 텍스트로 바꾸고, `speechSynthesis`는 텍스트를 음성으로 읽지만 지원과 품질은 브라우저와 언어별로 차이가 크다.

## 예시

```ts
const utterance = new SpeechSynthesisUtterance("저장되었습니다.");
utterance.lang = "ko-KR";
speechSynthesis.speak(utterance);
```

짧은 상태 안내를 음성 합성으로 제공하는 예다. 인식 기능은 권한, 네트워크, 언어 모델 제약을 별도로 봐야 한다.

## 면접 답변 예시

> Web Speech API는 browser의 음성 인식과 합성 기능을 web UI에서 사용하는 API 묶음입니다. 간단한 읽기 안내에는 유용하지만 지원 범위와 voice·language 품질이 환경마다 달라 핵심 기능의 유일한 입력 수단으로 두지는 않겠습니다. 음성 출력은 사용자 동작 뒤 시작하고 중지·반복 control과 text 대안을 함께 제공합니다. 인식 audio와 민감한 합성 문장은 주변에 노출되거나 외부 처리될 수 있으므로 권한 전 설명과 명시적 확인도 필요합니다.

## 장점

- 텍스트 콘텐츠를 빠르게 음성으로 제공할 수 있다.

## 단점

- 음성 인식은 권한과 개인정보 우려가 크다.

## 주의사항 / 실무 팁

- 언어와 음성 목록 로딩 실패를 처리한다.
